SF Pro is Cueue’s typeface: headings, body, labels, numbers in cards. The serif shows up only in big type: each page header (“Projects”, “Fernhill Outdoor · Trail Season 2026”) and the one display line a screen is about (“$15,500”, “The next move is clear.”). The serif is Mate: warm, slightly calligraphic, and it holds up at display size. Two alternates below for comparison.

Pairing rules

SF Pro is the typeface: headings, numbers in cards, body, labels and buttons.

Serif only for big type: the page header (Mate 44) and display moments (Mate 64). Never in cards, tables or nav.

Use it for the line the screen is about: the money on the month plan, the sign in statement, a brand headline.

If you’re not sure it’s a big moment, it isn’t. Use SF Pro.

Sentence case in both. No all caps eyebrows; use the 11px eyebrow style instead.
